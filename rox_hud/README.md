# rox_hud V3 — ROX Store
> © **ROX Store** — جميع الحقوق محفوظة.

- **ينضبط مع الخريطة تلقائي**: السكربت يحسب مكان الخريطة الصغيرة في شاشتك ويرسم حولها إطار، والحالة جنبها
- **الشارع والمنطقة** فوق الصحة، **الصحة والدرع** أشرطة ناعمة، والحالة **حلقات**: أكل، شرب، توتر، تحمل، أكسجين، مايك (برتقالي لما تتكلم، أزرق بالراديو)
- **عداد دائري** تحت يمين: علامات تضوي مع السرعة، قوس RPM، القير، البنزين، الحزام / المكينة / الأنوار / القفل
- **معلومات اللاعب** فوق يمين: ID، الوقت، الوظيفة والدوام، الكاش والبنك (يتحرك الرقم لما يتغير)
- **بوصلة** فوق بالنص
- **تحذير الصحة**: أطراف الشاشة تصير حمراء لما الصحة تقل
- **/hud**: إعدادات لكل لاعب (البوصلة، المعلومات، الخريطة وأنت ماشي، تحذير الصحة، إخفاء الـ HUD، اللون، km/h أو mph)
- يخفي شريط الصحة الأصلي تحت الخريطة واسم الشارع الأصلي

يشتغل مع QBCore / Qbox / ESX، و pma-voice، و LegacyFuel / ox_fuel.

```
ensure rox_hud
```
لا تشغله مع HUD ثاني. سكربتات ثانية تقدر تخفيه: `exports.rox_hud:SetHidden(true)`.
