# rox_hud — ROX Store
> © **ROX Store** — جميع الحقوق محفوظة.

HUD بستايل ROX: الصحة والدرع، الأكل والشرب والتوتر والتحمل والأكسجين، المايك، البوصلة واسم الشارع، وعداد السرعة داخل السيارة (السرعة، الـ RPM، القير، البنزين، الحزام `B`، المكينة، الأنوار).

يشتغل مع QBCore / Qbox / ESX (esx_status) و pma-voice و LegacyFuel / ox_fuel.

```
ensure rox_hud
```
الإعدادات في `config.lua`. لا تشغله مع HUD ثاني (مثل qb-hud) في نفس الوقت.
