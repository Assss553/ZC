# rox_emotes — ROX Store
Standalone. `ensure rox_emotes`.
- F5 or /emotes opens the menu. /e <name> plays an emote, /e c or X stops it.
- Tabs: favorites, emotes (some with props), dances, sit & lay, shared (hug, handshake...: the other player presses Y), walk styles, moods. Walk style and mood are saved.
- 6 quick slots: right-click an emote then a slot, set the keys in GTA settings > Key Bindings > FiveM.
- Add more animations in emotes.lua.
