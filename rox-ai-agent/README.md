# ROX AI AGENT — وكيل ذكاء اصطناعي لسطح مكتب Windows 11

تطبيق سطح مكتب (Electron + React/TypeScript) مع خادم Python محلي (FastAPI) يتيح لك مشاهدة Claude وهو يستخدم جهازك:
يرى الشاشة، يحرّك الماوس والكيبورد، يلعب الألعاب المدعومة، ينشئ المشاريع البرمجية، وينفّذ مهامّ مجدولة — مع نظام أمان وإيقاف طوارئ.

> **تنبيه صريح:** بُني المشروع واختُبر آلياً في بيئة Linux سحابية (الاختبارات، البناء، الواجهة، بث الشاشة عبر شاشة افتراضية).
> **لم يُشغَّل بعد على جهاز Windows 11 حقيقي**، لذا التحكم الفعلي بالماوس/الكيبورد ونوافذ الألعاب ومُثبِّت Windows يحتاج تجربتك الأولى.
> راجع [docs/FEATURES.md](docs/FEATURES.md) لحالة كل ميزة بدقة.

## المتطلبات
- Windows 11 (حساب مستخدم عادي — **لا تشغّله كمسؤول**)
- Python 3.10+ (فعّل "Add python to PATH")
- Node.js 20+ و Git
- إحدى طرق الاتصال بـ Claude (انظر أدناه)

## التثبيت (مرة واحدة)
افتح PowerShell (ليس كمسؤول) داخل مجلد المشروع:

```powershell
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned   # مرة واحدة إن لزم لتشغيل السكربتات
.\scripts\install-to-c.ps1      # ينسخ المشروع إلى C:\rox-ai-agent ويثبت كل شيء
# أو إن كان المشروع أصلاً في مكانه:
.\scripts\setup.ps1
```

`check-env.ps1` يفحص إصدار Windows و Python و Node و Git وصلاحيات المسؤول تلقائياً.

## التشغيل
```
scripts\run.bat
```
لإنشاء مُثبِّت Windows (Setup.exe) يضيف اختصاراً على سطح المكتب:
```powershell
.\scripts\build-installer.ps1
```

## ربط Claude الحقيقي (الإعدادات)
| الطريقة | المصادقة | الفوترة | ما تشغّله |
|---|---|---|---|
| **B · Claude API** | مفتاح API من console.anthropic.com يُحفظ في **Windows Credential Manager** | حسب الاستهلاك في حساب Console | كل شيء: المحادثة، التحكم بالكمبيوتر، الألعاب، البرمجة |
| **A · حساب Claude عبر Claude Code** | تسجيل الدخول الرسمي: `npm i -g @anthropic-ai/claude-code` ثم `claude` ثم `/login` | حسب اشتراكك/حسابك في Claude Code | وكيل البرمجة (محرك "Claude Code CLI") |
| **C · نموذج محلي** | — | — | **غير منفّذ بعد** (مكانه محجوز في الإعدادات) |

- اشتراك Claude Pro/Max **لا يشمل** استخدام الـ API؛ هما فوترتان منفصلتان.
- التطبيق لا يقرأ ولا ينسخ أي Cookies أو Tokens من تطبيق Claude.
- المفتاح لا يُكتب أبداً في الملفات أو قاعدة البيانات أو السجلات أو Git، ويظهر مُقنّعاً فقط.
- النموذج الافتراضي `claude-opus-5-5` مع تفكير تكيفي، وزر "اختبار الاتصال" يعرض النماذج المتاحة فعلياً لحسابك.
- الاستهلاك (توكنات الإدخال/الإخراج وعدد الطلبات) يُحسب من بيانات `usage` الرسمية في كل رد.

## الأقسام
- **لوحة التحكم:** بث حي حقيقي لسطح المكتب (WebSocket، تكبير/تصغير، ملء الشاشة)، حالة الوكيل، المهمة الحالية وتقدّمها، المعالج والذاكرة، مدة الجلسة، آخر الإجراءات.
- **المحادثة:** اكتب بالعربية مثل "أبيك تلعب وتكمل المهمة" ← يرد Claude ويقترح خطة ونوع الوكيل ← تضغط "موافقة وتشغيل". يدعم سجل المحادثات وإرفاق الصور ولقطة الشاشة.
- **وكيل الألعاب:** اختيار Adapter واللعبة ونافذتها، المهمة والمدة، Start/Pause/Resume/Stop، قرارات الوكيل، سجل الحركات والأخطاء، حفظ الحالة، اكتشاف تجمّد اللعبة واختفاء نافذتها والأخطاء المتكررة وطلب المساعدة.
  Adapters المتوفرة: Generic (تجريبي)، 2048 (أسهم فقط)، Solitaire، Minesweeper. لإضافة لعبة: `backend/rox/agents/game_adapters/base.py`.
- **التحكم بالكمبيوتر:** اكتب طلباً مثل "افتح VS Code وأنشئ مشروع FiveM جديداً"؛ يخطط ويفتح البرامج ويستخدم الماوس والكيبورد ويتحقق بلقطات الشاشة. يمكنك تعديل المهمة أثناء العمل. فيه أيضاً لوحة اختبار يدوي للماوس والكيبورد.
- **وكيل البرمجة:** ينشئ ويعدّل ملفات حقيقية داخل مجلد مسموح (Lua/FiveM، HTML/CSS/JS، Python، React…)، يشغّل الأوامر والاختبارات، يحفظ نسخة احتياطية قبل كل تعديل، يعرض الـ diff، خيار "مراجعة كل تغيير قبل اعتماده"، وزر تراجع. محرر مدمج مع تلوين الكود.
- **المهام المستقلة:** مثال "من 00:00 إلى 06:00 العب وأكمل المهمة". جدولة، إبقاء Windows مستيقظاً أثناء المهمة، إيقاف عند انتهاء الوقت، تقارير دورية، سجل زمني، استعادة بعد تعطل التطبيق (تظهر كـ interrupted ويمكن استئنافها تلقائياً)، خيار التشغيل عند تسجيل الدخول.
  **لا يعمل والجهاز مطفأ أو في وضع السكون**، ويجب أن يبقى التطبيق مفتوحاً.
- **سجل التدقيق:** كل إجراء (إدخال، أوامر، ملفات، موافقات، إعدادات) مسجّل.

## الأمان
- يعمل بصلاحيات المستخدم العادي (المُثبِّت `asInvoker`)، ويحذّر إن شُغّل كمسؤول.
- **إيقاف الطوارئ:** الزر الأحمر، أو `Ctrl+Alt+Pause` / `Ctrl+Alt+End` (يعمل حتى والنافذة في الخلفية)، أو تحريك الماوس بسرعة إلى زاوية الشاشة (failsafe). يوقف كل المهام ويحرر المفاتيح والأزرار.
- حذف الملفات، تثبيت البرامج، الشراء/الدفع، إرسال الرسائل ← يتطلب موافقتك في نافذة منبثقة.
- تغيير إعدادات الأمان، رفع الصلاحيات، الأوامر المدمّرة للنظام ← **محظورة دائماً**.
- الوصول للملفات محصور بالمجلدات التي تضيفها في الإعدادات. "الحذف" ينقل الملف إلى النسخ الاحتياطية بدل حذفه نهائياً.
- حدّ أقصى لتوكنات الإخراج، وحدّ زمني لكل مهمة.
- الخادم يستمع على `127.0.0.1` فقط مع رمز سري عشوائي لكل تشغيل.
- الألعاب: لقطات شاشة وإدخال نظام فقط، بلا حقن كود أو قراءة ذاكرة أو تجاوز Anti-Cheat. لا تستخدمه في ألعاب أونلاين تمنع الأتمتة.

## البيانات والنسخ الاحتياطي
- البيانات: `%LOCALAPPDATA%\ROX-AI-Agent` (قاعدة SQLite، السجلات، نسخ الملفات الاحتياطية).
- `scripts\backup.ps1` ينشئ نسخة مضغوطة من المشروع والبيانات في `Documents\ROX-Backups` (بدون مفاتيح API).
