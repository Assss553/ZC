# 🎬 استوديو الشورتس

تكتب فكرة ← يطلع لك مقطع شورت عمودي 1080×1920 بالستايل اللي تختاره ← يتجدول وينزل على قناتك في يوتيوب تلقائياً.

## التشغيل
```bash
cd shorts-studio
cp .env.example .env   # حط مفاتيحك
npm install
npm start              # http://localhost:4000
```
لازم يكون **ffmpeg** مثبت على جهازك.

## المفاتيح
| المفتاح | وش يسوي |
|---|---|
| `ANTHROPIC_API_KEY` | يكتب السيناريو والعنوان والوصف والهاشتاقات |
| `OPENAI_API_KEY` | يولد صورة لكل مشهد بجودة عالية ويسوي التعليق الصوتي |
| `GOOGLE_CLIENT_ID/SECRET` | يربط قناتك. سوّ OAuth Client من نوع Web في Google Cloud، وفعّل YouTube Data API v3، وحط رابط الرجوع `PUBLIC_URL/auth/youtube/callback` |

بدون مفاتيح يشتغل **وضع تجريبي** (خلفيات ملونة بدون صوت) عشان تجرب الجدولة.

## المميزات
- 8 ستايلات: أنمي، أنمي هادئ، أنمي أكشن، سينمائي، 3D، سايبربنك، كوميكس، رعب
- تختار كم مقطع باليوم (1–24) ولكم يوم، والمواعيد تتوزع على اليوم بالتساوي
- متى يبدأ: الحين / بعد ساعة / بعد ساعتين / بكرة / وقت محدد
- يبدأ ينتج كل مقطع قبل موعده بساعتين، وينشره على القناة في وقته
- لكل مقطع: معاينة، 🔄 تجديد، انشر الحين، تغيير الموعد، حذف
- حركة كاميرا على الصور، وترجمة مكتوبة على الشاشة، ونص المقطع بالعربي أو الإنجليزي
- المقاطع تنرفع مع علامة "محتوى مولّد بالذكاء الاصطناعي"

> لازم السيرفر يظل شغال عشان المجدول يشتغل، يعني شغله على VPS أو Koyeb أو Render.

## 🧠 الذكاء الاصطناعي الخاص (بدون أي مفتاح خارجي)
كل شي يشتغل على سيرفرك، ببلاش وبدون حدود:
| المهمة | البرنامج |
|---|---|
| كتابة السيناريو | **Ollama** + نموذج `qwen2.5:14b` (يدعم العربي) |
| الصور عالية الدقة | **Stable Diffusion WebUI Forge** + نموذج أنمي SDXL، مع تكبير ×1.5 |
| الصوت العربي | **Piper** (صوت `ar_JO-kareem`) |

```bash
./scripts/setup-local-ai.sh                 # يثبّت كل شي ويحط AI_MODE=local
cd sd-webui && ./webui.sh --api --listen    # سيرفر الصور
npm start
```
**السيرفر اللي تحتاجه:** Linux وكرت NVIDIA فيه 12GB VRAM أو أكثر، و32GB رام، و40GB مساحة. تقدر تستأجر واحد من RunPod أو Vast.ai بحوالي 0.3 إلى 0.5$ بالساعة.
ربط يوتيوب بس هو اللي يظل يحتاج `GOOGLE_CLIENT_ID`، لأن جوجل ما تسمح بالرفع إلا عن طريقها.
