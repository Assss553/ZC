# ROX Game Translator - مترجم ألعاب PS4 / PS5 للعربية

يترجم حوارات الألعاب والقوائم والكلمات الأجنبية إلى العربية مباشرة وأنت تلعب، بدون أي تعديل على جهاز البلايستيشن.

## طريقة العمل
1. تبث اللعبة إلى الكمبيوتر عبر **PS Remote Play** (اتصال لاسلكي، مجاناً من سوني) أو عبر **جهاز التقاط** (Capture Card) بسلك USB.
2. الأداة تصوّر منطقة الحوار، تقرأ النص (OCR)، تترجمه للعربية.
3. تظهر الترجمة في نافذة شفافة فوق اللعبة دائماً.

## التشغيل (Windows)
1. ثبّت [Python 3.10+](https://www.python.org/downloads/) (فعّل خيار *Add to PATH*).
2. افتح PS Remote Play أو برنامج جهاز الالتقاط واعرض اللعبة.
3. اضغط مرتين على `start_windows.bat`.
4. اضغط **تحديد المنطقة** واسحب حول مكان الحوار (أو القائمة).
5. اضغط **تشغيل/إيقاف** أو زر **F8**.

> أول تشغيل يحمّل محرك قراءة النص (حوالي 100MB) ويحتاج إنترنت للترجمة.

## الإعدادات (`config.json`)
| الإعداد | المعنى |
|---|---|
| `source_lang` | لغة اللعبة: `en` إنجليزي، `ja` ياباني، `fr`... |
| `interval` | كل كم ثانية يقرأ الشاشة |
| `min_conf` | دقة قراءة الحروف المطلوبة (0 إلى 1) |
| `font_size` | حجم الخط العربي |

الكلمات والقوائم المترجمة تُحفظ في `cache.json` فلا تُترجم مرتين.

## على الهاتف
حالياً الأداة تعمل على الكمبيوتر. النسخة القادمة للهاتف (أندرويد) تستخدم نفس الفكرة مع تطبيق Remote Play.
