# ROX Laundry (© ROX Store)

Walk-in laundromat map + wash / dry / fold minigame.

## Install
1. Put `rox_laundry` in your resources and add `ensure rox_laundry` to server.cfg.
2. Join, go to a flat empty lot, stand where the shop door should be, look towards where the shop should stand
   and type `/roxlaundry_here` (needs ace `rox_laundry.admin`, e.g. `add_ace group.admin rox_laundry.admin allow`).
   The spot is saved on the server. Or set `Config.Location` (centre of the building, street level, heading).

## Play
- Real GTA props: 25 washers, 9 dryers, folding tables, cashier counter + till, office chair, waiting chairs, vending machines, plants (edit `shared/props.lua`).
- **Washer**: drag the dirty T-shirt in → pour detergent (stop in the green zone) → pick the temperature from the care tag → insert coins → fix the unbalanced load alert → take the T-shirt out.
- **Dryer**: load the wet T-shirt → pick the heat from the care tag → pay → clean the lint filter when it clogs → take it out.
- **Folding table**: fold the sleeves, the side and the bottom in order.
- Quality (stars) from every step → money reward (`Config.Reward`), optional item reward / required dirty item.
- ESX, QBCore, ox_inventory or standalone. Arabic / English (`Config.Locale`).

## Files
- `stream/rox_laundromat.ydr` (building shell: walls, floor, ceiling, lights, signs, collision) + GTA props from `shared/props.lua`, `rox_laundry_txd.ytd`, `rox_laundry.ytyp`
- Generated by `tools/shellgen/laundry.py` (`python3 build.py <work> laundry`).
