# ROX Store — متجر ملابس بتصاميم الذكاء الاصطناعي

متجر إلكتروني حقيقي متكامل: واجهة متجر + لوحة تحكم + قاعدة بيانات PostgreSQL + ذكاء اصطناعي يصمّم المنتجات + إيميلات للعملاء + طبقة حماية.

## التشغيل

يحتاج **Node.js 22.13 أو أحدث**.

```bash
npm install
cp .env.example .env      # عدّل القيم (مفتاح الذكاء الاصطناعي، SMTP...)
npm start
```

- المتجر: `http://localhost:3000`
- لوحة التحكم: `http://localhost:3000/admin/`

**أول دخول:** افتح لوحة التحكم، وأنشئ حساب الأدمن باستخدام **رمز الإعداد** اللي يظهر في سجل الخادم (أو قيمة `SETUP_TOKEN`).
أو من سطر الأوامر: `npm run create-admin -- you@mail.com "كلمة-مرور-قوية-2026"` (ينفع كذلك لاسترجاع كلمة المرور).

## المميزات

### المتجر
- تصميم بهوية ROX (أسود/أحمر، خطوط مائلة، Bebas Neue + Tajawal)، ويشتغل على الجوال.
- فلترة وترتيب، صفحة منتج بالمقاسات والكمية والمواصفات، سلة، شحن مجاني فوق مبلغ معيّن.
- إتمام الطلب (دفع عند الاستلام / تحويل بنكي) وتتبّع الطلب برقمه + الإيميل.
- عدّاد للإصدار الجاي، روابط الحسابات، ووضع صيانة.

### استوديو الذكاء الاصطناعي
اكتب فكرة (مثل: "هوديات مستوحاة من ليل الرياض") ويطلع لك Claude:
**الرسمة + الألوان + الاسم + الوصف + السعر + المواصفات**، وتنحفظ مسودات تراجعها وتنشرها بضغطة (أو تنشرها مباشرة).
الصور تتولد على شكل قطع حقيقية: هودي، تيشيرت، سويت شيرت، كاب، شنطة، ماوس باد. وتقدر ترفع صورة حقيقية لأي منتج.

### لوحة التحكم
نظرة عامة (المبيعات، المؤشرات، الأعلى مبيعًا)، الطلبات (فلترة، بحث، تغيير الحالة مع إيميل للعميل، اتصال/واتساب)، المنتجات والمخزون، الإعدادات، والأمان (سجل النشاط، الجلسات، سجل الإيميلات).

### الإيميلات
- تأكيد الطلب للعميل (مع بيانات التحويل إذا اختار تحويل بنكي).
- إيميل تلقائي عند تغيير الحالة (قيد التجهيز، تم الشحن، تم التوصيل، ملغي).
- تنبيه لصاحب المتجر عند كل طلب جديد.

## الحماية
| الخطر | الحماية |
|---|---|
| سرقة كلمات المرور | تشفير scrypt مع ملح عشوائي |
| تخمين كلمة المرور | قفل الحساب 15 دقيقة بعد 5 محاولات + تحديد معدل الطلبات |
| سرقة الجلسة | كوكي HttpOnly + Secure + SameSite=Strict، تنتهي بعد 12 ساعة |
| CSRF | رمز سري لكل جلسة + التحقق من مصدر الطلب |
| حقن SQL | كل الاستعلامات مُعاملة (parameterized queries) |
| بيع أكثر من المخزون | قفل الصف (FOR UPDATE) وخصم ذرّي داخل معاملة |
| XSS | CSP صارمة (بدون سكربتات داخلية) + تنظيف كل المدخلات والمخرجات |
| التلاعب بالأسعار | السعر والإجمالي يُحسبان في الخادم فقط |
| ملفات خبيثة | الرسومات تُبنى من قائمة بيضاء، والصور المرفوعة يُفحص محتواها الحقيقي |
| السبام والبوتات | حقل فخ مخفي + حد للطلبات لكل جهاز |
| حقن ترويسات الإيميل | تنظيف المستلم والموضوع |
| Clickjacking وغيرها | ترويسات Helmet (frame-ancestors none، HSTS، nosniff…) |

تشغيل الاختبارات: `npm test` (على PGlite)، أو على Postgres حقيقي: `TEST_DATABASE_URL=postgres://... npm test`

## النشر المجاني على Netlify (الطريقة الموصى بها)

ما يحتاج أي مفتاح ولا موقع ثاني: Netlify يسوي **قاعدة بيانات PostgreSQL تلقائيًا** (Netlify Database) أول ما ينشر المتجر، والموقع **ما ينام**.

1. ادخل https://netlify.com وسجّل بـ **GitHub**.
2. **Add new project ← Import an existing project ← GitHub** واختر `Assss553/ZC`، الفرع `main`، واضغط **Deploy**.
   الإعدادات كلها جاهزة في `netlify.toml` (الصفحات من `public/` والخادم من `netlify/functions/`).
3. غيّر الاسم: **Project configuration ← Change project name** واكتب `rox` ← يصير الرابط `rox.netlify.app` (إذا الاسم متاح).
4. **Project configuration ← Environment variables** وأضف:
   - `SETUP_TOKEN` = كلمة سرية تختارها (لإنشاء أول أدمن)
   - `ANTHROPIC_API_KEY` = مفتاح Claude (اختياري)
   - `SMTP_HOST`, `SMTP_USER`, `SMTP_PASS`, `MAIL_FROM` للإيميلات (اختياري)
5. **Deploys ← Trigger deploy** عشان تنطبق المتغيرات، وافتح `/admin/`.

تأكد إنه شغال: افتح `/healthz` لازم يطلع `{"ok":true,"db":"postgres"}`.

> استوديو الذكاء الاصطناعي يشتغل على Netlify كـ **دالة بالخلفية** (لين 15 دقيقة) لأن التصميم ياخذ أكثر من مهلة الطلب العادية.
> الخطة المجانية فيها 300 رصيد بالشهر؛ إذا خلص الرصيد يتوقف الموقع لين الشهر الجاي.

## النشر المجاني على Render + Neon (بديل)

الموقع يشتغل على **Render** (استضافة مجانية) وقاعدة البيانات على **Neon** (PostgreSQL مجانية ودائمة، 0.5 جيجا).
ليش قاعدة خارجية؟ لأن قرص الاستضافة المجانية ينمسح مع كل تشغيل، فلو خلّينا البيانات عليه بتضيع الطلبات.

**1) قاعدة البيانات (Neon)**
1. سجّل في https://neon.tech وسوِّ مشروع جديد باسم `rox` (اختر منطقة Frankfurt).
2. من **Connection string** انسخ الرابط (يبدأ بـ `postgresql://` وينتهي بـ `sslmode=require`).

**2) الموقع (Render)**
1. سجّل في https://render.com بحساب GitHub، واسمح له يوصل لمستودع `assss553/zc`.
2. **New → Blueprint**، اختر المستودع والفرع، وRender يقرأ `render.yaml` ويسوي خدمة باسم **rox**.
3. لما يطلب القيم: الصق رابط Neon في `DATABASE_URL`، ومفتاح Claude في `ANTHROPIC_API_KEY`، وبيانات الإيميل (أو اتركها لبعدين).
4. اضغط **Apply**. بعد دقائق يصير الموقع على `https://rox.onrender.com` (أو `rox-xxxx` إذا الاسم محجوز).

**3) أول دخول**
افتح `/admin/`، وخذ **رمز الإعداد** من Render ← خدمة rox ← **Environment** ← `SETUP_TOKEN`.

> الخطة المجانية في Render تنوّم الموقع بعد 15 دقيقة بدون زوار، وأول زيارة بعدها تاخذ حوالي دقيقة. للتشغيل الدائم تحتاج خطة مدفوعة (حوالي 7$ شهريًا).
> الجداول تنشأ تلقائيًا أول ما يشتغل الخادم. ومحليًا بدون `DATABASE_URL` يستخدم PGlite (Postgres مدمجة) في `data/pglite`.

## النشر على سيرفر خاص
1. أي سيرفر Node.js 22 مع قاعدة PostgreSQL (أو Supabase / Neon).
2. اضبط `NODE_ENV=production` و `DATABASE_URL` و `PUBLIC_URL`، وفعّل **HTTPS**.
3. إذا خلف بروكسي (Nginx/Cloudflare) اضبط `TRUST_PROXY=1`.
4. النسخ الاحتياطي: Neon يحتفظ بنسخ تلقائية، أو استخدم `pg_dump`.
> الدفع بالبطاقة (مدى/فيزا/Apple Pay) يحتاج ربط بوابة دفع مثل Moyasar أو Tap أو HyperPay بحساب تجاري، وهذا غير مفعّل حاليًا.
