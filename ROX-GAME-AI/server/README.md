# ROX Server (Windows)
برنامج يعمل على الكمبيوتر، ويربط بين البلايستيشن وتطبيق ROX على الجوال.

## طريقة العمل
```
PS4/PS5 ──(Remote Play عبر chiaki-ng الرسمي)──► نافذة اللعبة على الكمبيوتر
                                                  │
                            ROX Server: OCR + ترجمة + Safe Vision (على كرت الشاشة)
                                  │                          │
                   ترجمة فوق نافذة اللعبة       جوال ROX عبر WiFi (منفذ 9750)
```
- **الاقتران وتسجيل الدخول:** يتمّان داخل [chiaki-ng](https://github.com/streetpea/chiaki-ng)، وهو عميل Remote Play مفتوح المصدر وتثبّته من صفحته الرسمية. تسجيل الدخول يكون من صفحة Sony الرسمية، ثم تدخل رمز الاقتران. **ROX لا يطلب الإيميل أو كلمة المرور ولا يراهما.**
- **عزل الترخيص:** ROX Server لا يدمج كود chiaki-ng داخله، فهو برنامج منفصل يقرأ صورة نافذته فقط. لذلك لا يُفرض ترخيص AGPL على ROX.
- **الترجمة:** تتم على الكمبيوتر بدون إنترنت باستخدام نماذج Argos Translate. يُنزَّل كل نموذج مرة واحدة فقط، ويُستخدم كرت NVIDIA تلقائيًا إذا كان موجودًا.

## التشغيل
1. ثبّت chiaki-ng، وسجّل الدخول، واقترن بجهازك، ثم ابدأ البث.
2. شغّل `ROX-Server.exe`، واختر نافذة chiaki، ثم اضغط **AUTO START**.
3. في تطبيق ROX على الجوال: افتح **ربط PlayStation**، ثم **البحث عن ROX Server**، ثم **اتصال**.
4. اسمح لبرنامج ROX Server في جدار حماية Windows بالاتصال على **الشبكات الخاصة** (المنفذان 9750 و9751).

## الترخيص
يستخدم ROX Server مكتبة **NudeNet**، وهي نموذج مدرَّب لكشف الأجزاء المكشوفة من الجسم وتحديد مكانها، ومرخصة بترخيص AGPL-3.0. لذلك يُنشر ROX Server كاملًا بنفس الترخيص، وتجد نص الترخيص في `LICENSE-AGPL-3.0.txt`، والكود المصدري كاملًا موجود في هذا المجلد.
