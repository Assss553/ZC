# ROX GAME AI — تطبيق Android

تطبيق Android واحد (Kotlin + Jetpack Compose) يترجم ألعاب PS4/PS5 إلى العربية ويحجب المشاهد غير المناسبة، وتتم المعالجة كلها على الهاتف افتراضيًا.

> **الحالة:** المشروع يُبنى تلقائيًا على GitHub Actions. الاختبارات الآلية تستخدم **فيديو تجريبيًا مدمجًا**، ولم يُختبر حتى الآن على جهاز PlayStation حقيقي أو على هاتف حقيقي. راجع `tests/TESTING.md` لمعرفة ما اختُبر وما لم يُختبر.

## التنزيل والتثبيت
1. افتح صفحة **Releases** في المستودع، أو استخدم الرابط المباشر لآخر إصدار:
   `https://github.com/assss553/zc/releases/latest/download/ROX-GAME-AI.apk`
2. على الهاتف (Android 10 أو أحدث): اسمح بـ"تثبيت التطبيقات من مصادر غير معروفة" للمتصفح أو مدير الملفات، ثم افتح الملف.
3. إذا كان الملف مبنيًا بنسخة Debug، فاحذف النسخة القديمة قبل تثبيت نسخة جديدة بُنيت بمفتاح مختلف.

## طريقة الاستخدام
1. **ربط PlayStation:** اضغط "البحث عن PS4 / PS5" ثم "اقتران". يجب أن يكون الهاتف والجهاز على نفس شبكة Wi-Fi.
2. **مصدر الفيديو** (من إعدادات الاتصال):
   - **بطاقة التقاط HDMI عبر USB-C:** تعطي أفضل نتيجة، لأن الحجب يتم قبل عرض الإطار فعليًا. تحتاج هاتفًا يدعم الكاميرات الخارجية (UVC)، ويجب إيقاف HDCP من إعدادات الجهاز نفسه.
   - **PS Remote Play:** تطبيق Sony الرسمي يبث اللعبة إلى الهاتف، وROX يلتقط الشاشة بعد موافقتك ويعرض الترجمة في نافذة عائمة فوق اللعبة.
   - **فيديو تجريبي:** لاختبار جميع الميزات بدون جهاز.
3. اضغط **AUTO START**. ينفّذ النظام بالترتيب: اكتشاف المصدر، ثم استقبال الصورة والصوت، ثم التعرف على اللعبة، ثم تحديد اللغة، ثم تشغيل الترجمة والصوت وSafe Vision، ثم تطبيق إعدادات اللعبة وعرض الصورة المعالجة. وللإيقاف اضغط **STOP**.

## الميزات وما يدعمها تقنيًا
| الميزة | التنفيذ |
|---|---|
| الاقتران اللاسلكي | بروتوكول اكتشاف الأجهزة على الشبكة المحلية (UDP 987/9302): اكتشاف PS4 وPS5، ومعرفة حالة التشغيل أو الراحة، واسم اللعبة المشغلة، وحفظ الأجهزة، وإعادة الاتصال تلقائيًا حتى عند تغيّر عنوان IP |
| التعرف على اللعبة | اسم اللعبة الذي يرسله الجهاز نفسه، ثم مطابقة نص الشاشة مع المكتبة، وإن لم ينجح ذلك يظهر اختيار يدوي. لكل لعبة ملف إعدادات وسجل |
| ROX LIVE TRANSLATOR | ML Kit OCR على الهاتف (لاتيني، ياباني، صيني، كوري) مع تحديد اللغة والترجمة إلى العربية، وتصنيف النص (حوار، قائمة، مهمة، إشعار، أداة)، ومنع تكرار ترجمة النص نفسه، وحفظ سياق الحوار وسجله |
| ROX VOICE TRANSLATOR | Android SpeechRecognizer: على Android 13 وما بعده يلتقط صوت اللعبة مباشرة، وعلى الإصدارات الأقدم يستخدم الميكروفون. اسم المتحدث يؤخذ من الترجمة الظاهرة على الشاشة، والدبلجة العربية تجريبية عبر TTS |
| ROX SAFE VISION | كشف مناطق الجلد المكشوفة مع تتبعها بين الإطارات، وحجبها بأربعة أنماط (Gaussian وPixelation وBlack وFull Scene)، وفك الحجب تلقائيًا، ومناطق مخصصة، وسجل للمشاهد المحجوبة. يتم ذلك **قبل** نشر الإطار للعرض |
| الأداء | قياس فعلي للذاكرة والمعالج وعدد الإطارات في الثانية والتأخير والحرارة، مع تخفيف الحمل تلقائيًا عند ارتفاع الحرارة |

## قيود حقيقية يجب معرفتها
- **لا توجد واجهة رسمية:** Sony لا توفر واجهة برمجة عامة لاستقبال بث PS4/PS5. لا يحاول ROX تجاوز حماية Sony أو DRM أو HDCP، ويعتمد على تطبيق Sony الرسمي أو على بطاقة التقاط.
- **حماية التقاط الشاشة:** إذا منع تطبيق Remote Play التقاط شاشته أو صوته، يصل الفيديو أسود أو الصوت صامتًا. يكتشف ROX ذلك ويسجّله في السجلات ولا يخفيه.
- **دقة الحجب:** فوق Remote Play يُرسم الحجب في نافذة عائمة، وقد يتأخر إطارًا واحدًا تقريبًا. الحجب المضمون قبل العرض يتحقق فقط في العرض داخل التطبيق (بطاقة الالتقاط أو الفيديو التجريبي).
- **فئتا العري والمحتوى الجنسي:** تحتاجان نموذج تصنيف مدربًا لم يُضمَّن بسبب ترخيصه. ضع ملف `model.tflite` وملف `labels.txt` في `android/app/src/main/assets/safevision/` لتفعيلهما. الكاشف المفعّل حاليًا كاشف مناطق جلد يعتمد على خوارزمية وليس على نموذج مدرب.
- **نماذج الترجمة:** يحتاج كل زوج لغات إلى تنزيل نموذجه مرة واحدة عبر الإنترنت (حوالي 30MB).

## هيكل المشروع
```
ROX-GAME-AI/
  android/app/src/main/java/com/rox/gameai/
    core/         الإعدادات والتخزين والسجلات وقياس الأداء
    connection/   اكتشاف PS4/PS5 والاتصال وإعادة الاتصال
    ai/           OCR والتعرف على اللعبة وتصنيف النص
    translation/  محرك الترجمة والذاكرة المؤقتة وسياق الحوار
    voice/        الترجمة الصوتية والدبلجة التجريبية
    vision/       مصادر الفيديو وSafe Vision والتتبع
    pipeline/     AUTO START وخدمة الالتقاط والنافذة العائمة
    ui/           الواجهة (عربي RTL / إنجليزي)
  android/app/src/test/         اختبارات JVM
  android/app/src/androidTest/  اختبارات على المحاكي
  tests/TESTING.md              نتائج الاختبارات
  release/                      يضع CI فيه ملفات APK
```
> المجلدات core وai وtranslation وvoice وvision وconnection موجودة كحزم داخل وحدة Android واحدة، لأن التطبيق يُبنى كملف APK واحد.

## توقيع نسخة Release (بدون وضع أي مفتاح في المستودع)
أنشئ المفتاح مرة واحدة على جهازك:
```
keytool -genkeypair -v -keystore rox-release.jks -alias rox -keyalg RSA -keysize 4096 -validity 10000
base64 -w0 rox-release.jks > rox-release.b64
```
ثم أضف في GitHub: **Settings ← Secrets and variables ← Actions** الأسرار التالية:
`ROX_KEYSTORE_BASE64` (محتوى الملف .b64) و`ROX_KEYSTORE_PASSWORD` و`ROX_KEY_ALIAS` و`ROX_KEY_PASSWORD`.
بعدها يبني كل تحديث نسخة `ROX-GAME-AI.apk` موقعة بمفتاح الإصدار. احتفظ بنسخة احتياطية من ملف المفتاح، لأن فقدانه يمنع تحديث التطبيق.

`cd ROX-GAME-AI/android && ./gradlew assembleDebug testDebugUnitTest`
