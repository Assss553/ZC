# ROX Store — متجر FiveM

متجر كامل مع لوحة تحكم. الملفات ثابتة (HTML/JS) وتشتغل على أي استضافة، والبيانات والحسابات والحماية على Supabase.

## محتويات المجلد

| المسار | وش هو |
|---|---|
| `site/` | **هذا المجلد اللي ترفعه على الاستضافة** |
| `site/index.html` | المتجر |
| `site/admin.html` | لوحة التحكم |
| `site/rox-config.js` | رابط مشروع Supabase والمفتاح العام — **الملف الوحيد اللي تعدّله** |
| `site/rox-receipt-check.js` | محرك فحص إيصالات التحويل |
| `site/vendor/` | مكتبة الاتصال بـ Supabase (نسخة محلية) |
| `site/_headers` `site/.htaccess` `site/vercel.json` | ترويسات الحماية لكل نوع استضافة |
| `supabase/rox-setup.sql` | إعداد قاعدة البيانات والصلاحيات — يتشغّل مرة وحدة |

## الإعداد (مرة وحدة)

1. **أنشئ مشروع** في [supabase.com](https://supabase.com).
2. **أنشئ حسابك:** Authentication ← Users ← Add user. اكتب إيميلك وكلمة مرور قوية وفعّل Auto Confirm User.
   لازم يكون **أول حساب** في المشروع، لأن أقدم حساب هو اللي يصير أدمن.
3. **شغّل قاعدة البيانات:** SQL Editor ← الصق محتوى `supabase/rox-setup.sql` ← Run.
   آخر سطر في النتيجة يكتب إيميل الأدمن.
4. **اربط الموقع:** Project Settings ← API، انسخ Project URL والمفتاح العام (anon) وحطهم في `site/rox-config.js`.
5. **روابط الإيميل:** Authentication ← URL Configuration، حط رابط موقعك في Site URL، عشان روابط تأكيد الحساب وتغيير كلمة المرور ترجع لموقعك.
6. **ارفع محتوى `site/`** على الاستضافة (الطرق تحت).
7. افتح `/admin.html`، سجّل دخولك، وسجّل **كلمة المرور الثانية** فورًا.

## الرفع على الاستضافة

- **Netlify:** اسحب مجلد `site` على صفحة Deploys، أو اربط المستودع وحط Publish directory = `rox-fivem/site`.
- **Cloudflare Pages:** مشروع جديد ← Upload assets ← ارفع محتوى `site`.
- **Vercel:** اربط المستودع وحط Root Directory = `rox-fivem/site`.
- **GitHub Pages:** ارفع محتوى `site` على فرع النشر. (ما يدعم ترويسات الحماية، والحماية الأساسية داخل الصفحات تبقى شغّالة.)
- **استضافة عادية (cPanel):** ارفع محتوى `site` داخل `public_html`، مع ملف `.htaccess`.

لازم الموقع يشتغل على **https**.

## كلمات المرور

ما فيه أي كلمة مرور مكتوبة في الملفات، وهذا مقصود: أي شي داخل ملفات الموقع يقدر الزائر يقراه.

- **كلمة مرور الحساب:** اللي تكتبها أنت في Supabase في الخطوة 2. تغيّرها من Authentication ← Users.
- **كلمة المرور الثانية:** تسجّلها أنت أول مرة تدخل اللوحة، وتغيّرها من الإعدادات ← الأمان. محفوظة مشفّرة في قاعدة البيانات.
- لو نسيت الثانية: من SQL Editor شغّل `update admins set pin_hash = null, fails = 0, locked_until = null;` وبتطلب منك اللوحة تسجّل وحدة جديدة.

## ملاحظات أمان

- المفتاح العام (anon) آمن يكون في `rox-config.js`. **لا تحط مفتاح `service_role` في أي ملف.**
- صلاحيات اللوحة محمية في قاعدة البيانات نفسها، مو بس في الواجهة.
- فاحص الإيصالات مساعد للمراجعة وليس إثباتًا. تأكد من كشف حسابك قبل التسليم.
